# Cómo publicar en Research

1. En GitHub entra a `content/research/` → **Add file → Create new file**.
2. Nombre: `AAAA-MM-DD-titulo-corto.md` (ej. `2026-11-03-semana-cambiaria.md`).
3. Copia la plantilla de `_plantilla.md`, llena los datos y escribe el texto debajo de la segunda línea `---`.
4. Para adjuntar un PDF: súbelo a `public/research/` y pon su nombre en `pdf:`.
5. Versión en inglés (opcional): crea el mismo nombre terminado en `.en.md`.
6. **Commit changes**. La página lo muestra en 1–2 minutos (Vercel vuelve a publicar solo).

Los archivos que empiezan por `_` no se publican.
