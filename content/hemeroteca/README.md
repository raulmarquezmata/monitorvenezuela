# Hemeroteca 2026

`noticias.json` es el archivo de noticias curadas (el mismo formato del dashboard anterior):
`cat`, `date` ("29 oct 2026", "oct 2026" o "sept-oct 2026"), `es.title/preview/body`, `en.title`, `sectors`, `sources[{text,url}]`.

Para actualizarla: reemplaza `noticias.json` por la exportación nueva (GitHub → este archivo → ✏️ o **Add file → Upload files**).
Vercel publica el cambio en 1–2 minutos. Categorías: oil, mac, fin, pol, jur, inv, mkt, min.
